# Basic SQL Lab (SQLite)

This notebook introduces relational databases using SQLite, which runs locally
inside the notebook and does not require a separate database server.

## Open the lab

[![Launch in Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/ntious/FundIT/HEAD?labpath=Database_basic_SQL_lite/SQL_Lab.ipynb)

The link opens the actual notebook, `SQL_Lab.ipynb`. It may take a few minutes
to build the first time. Binder sessions are temporary; download your notebook
or database file before closing the session.

To run locally, use a Jupyter environment. From the repository root, install
the dependencies with `python -m pip install -r .binder/requirements.txt`, then
open `Database_basic_SQL_lite/SQL_Lab.ipynb` and run cells from top to bottom.

## What you will practice

- Creating related tables and primary/foreign keys
- Inserting sample rows
- Querying, filtering, and joining data
- Updating and deleting rows

The notebook creates `StudentDB_demo.db` in its working directory. Use the
synthetic example data only; do not enter real student or personal information.
Save a copy of the notebook and any required query output as your submission
evidence, following your instructor's directions.
